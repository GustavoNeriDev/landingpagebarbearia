Victor do Corte — Barbearia

Landing page responsiva desenvolvida para a **Victor do Corte Barbearia**, com foco em apresentar os serviços, valores e facilitar o agendamento diretamente pelo WhatsApp, sem necessidade de formulários ou cadastros.

🔗 **Site no ar:** [barbeariavictordocorte.vercel.app](https://barbeariavictordocorte.vercel.app/)

---

## Sobre o projeto

O objetivo do projeto foi criar uma página de vendas simples e direta para uma barbearia, reduzindo a fricção entre o visitante e o agendamento. Em vez de formulários de contato, cada serviço possui um botão que abre o WhatsApp já com uma mensagem pré-formatada, indicando o serviço escolhido.

---

## Funcionalidades

 **Menu de navegação fixo** com rolagem suave até cada seção (Início, Sobre Nós, Serviços, Galeria, Tabela, Localização, Contato)
 **Agendamento via WhatsApp**: cada botão "Agendar" nos cards de serviço redireciona para o WhatsApp com uma mensagem automática correspondente ao serviço clicado
 **Seção de serviços** com cards individuais (Corte, Corte + Sobrancelha, Corte + Barba, Corte + Barba + Sobrancelha), exibindo preço e ação de agendar
 **Galeria de fotos** com os cortes realizados na barbearia
 **Tabela de preços** resumida com todos os serviços e valores
 **Mapa incorporado do Google Maps** mostrando a localização física da barbearia
 **Design responsivo (mobile-first)**, adaptado para funcionar bem em celulares, tablets e desktop
 **Página secundária de agendamento** (`paginasecundaria/`), acessada pelos botões "Agendar agora"

---

##  Tecnologias utilizadas

- **HTML5** — estruturação semântica do conteúdo
- **CSS3** — estilização, layout responsivo e identidade visual (tema escuro preto/dourado)
- **JavaScript** — interatividade, rolagem suave do menu e geração dos links de WhatsApp com mensagem automática
